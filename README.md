# 🍲 Family Recipe Memory

> Preserve voice recipes and stories from loved ones using Local AI + Backboard Persistent Memory.

## Problem

Family culinary heritage is often trapped in unwritten spoken traditions. Audio notes from grandmothers or parents contain precious nuances, but searching through raw voice recordings is frustrating and inefficient.

## Solution

**Family Recipe Memory** turns unstructured voice notes into a searchable family knowledge base. Audio transcription and AI structured parsing run **100% locally**, ensuring raw voice recordings never leave your machine. Only extracted text is persisted in Backboard memory for cross-session natural language retrieval.
